# Vue 原型 01 交付与后续接入说明

## 设计与技术选择

检查了 v0.2.0 的 `studio/ui.py`、`studio/workspace.py` 及既有验证记录，保留“项目素材 → 镜头 → 图像/视频 → 原条目版本历史”的结构。新增前端完全在 `prototypes/vue-workbench/` 中，Qt 源码和 EXE 没有改动。

三栏比例在 1920 CSS 像素下为 192 像素导航、弹性工作区、340 像素助手。1080p 默认显示两个完整制作中的镜头，时间轴保持在底部。4K CSS 视口限制工作台最大宽度 2560，避免卡片无限拉长。窄于 1100 时助手改为抽屉；窄于 800 时卡片描述移至媒体上方；窄于 580 时媒体逐列排列。

视觉以参考图的白色卡片、宽幅图片、细边框、柔和间距、克制蓝色为基础。正文字色独立于辅助提示色，避免所有文字都变成浅灰。没有大面积渐变、毛玻璃或装饰动画。

Pinia 用于项目、选中对象、助手与队列的共享状态；Reka UI 提供有焦点约束与键盘支持的弹窗及菜单；不用完整组件库以免统一原生控件风格盖过设计。模拟逻辑放在 store，展示组件通过 props、事件与 ID 请求操作。

## 与 Qt v0.2.0 的覆盖差异

| 能力 | Vue 原型 | Qt v0.2.0 |
| --- | --- | --- |
| 导航、角色/场景/镜头、编辑与关联 | 可操作的独立 Mock Data | 真实项目 |
| 项目存储 | 浏览器独立 localStorage + 导出原型 JSON | 磁盘项目文件、媒体及 journal |
| 生成和版本历史 | 模拟进度，原 ID 保存示例画面版本 | ComfyUI 真实任务与输出 |
| AI 对话、工具建议和审阅 | 本地规则回复；确认后模拟队列 | DeepSeek、按需 skill、真实工具执行 |
| 模型选择与联网 | 模拟选择，无远程请求 | 实际模型列表与联网检索 |
| 工作流与参数 | 图片/视频分组及代表性参数界面 | 所有批准工作流、节点、LoRA 和合法帧数校验 |
| 视频 | 静帧模拟预览与进度条 | 真实媒体及原生播放器 |
| 队列恢复 | 浏览器模拟任务恢复 | ComfyUI 查询、prompt_id、journal 幂等恢复 |
| 媒体导入与文件夹选择 | 本阶段无本机文件导入 | 本地素材导入、复制及保存 |
| 图片查看 | 示例媒体缩放 | 实际原图像素查看 |
| Windows 打包 | 无桌面壳；浏览器运行 | 现有 EXE 保留 |

完整服务行为仍需以后接回现有 Python；原型通过不能作为真实生成、取消或崩溃恢复已经迁移的证据。

## 后续接入 Python 需要的改造

1. **先抽离控制层。** 将 Qt 窗口中的项目/生成/助手协调代码提取为不依赖控件的服务；保留现有 `Project`、工作流构造与 ComfyUI/DeepSeek 模块。Qt 入口仍可调用相同服务，便于对照测试。
2. **建立命令与事件接口。** 前端通过一个 Gateway 提交读取项目、编辑素材、创建生成任务、取消、恢复查询等命令。进度与完成事件包含 project_id、target_id、job_id 和 sequence，按目标 ID 更新原卡片；不能根据当前选中卡片分配结果。
3. **在前端 DTO 与现有格式之间映射。** Vue 的 Mock 类型不应直接覆盖 Python `schema=1`。将 image/current/videoVersion 等展示字段映射到已有数据，保留原素材 ID、相对路径、历史意图与参数；做保存/重开/旧项目对照回归。
4. **任务由 Python 持有。** 移除浏览器计时器，以真实 ComfyUI 事件展示进度；缺少步数时展示阶段，不伪造总百分比。任务 journal、超时未知状态和幂等恢复继续在 Python 执行。
5. **审阅不能只靠按钮。** 让 Python 生成有 ID 的待审阅操作及参数快照，确认后才执行；服务端验证目标、参数和操作权限。取消、拒绝、目标删除及重复确认都必须有明确结果。
6. **媒体与凭据留在本机服务。** 图片/视频改为受控的媒体地址，视频服务支持 Range 请求；文件导入、保存位置及模型目录由服务验证。DeepSeek Key 留在现有 Windows 凭据管理器，不发给浏览器，不写进前端构建。
7. **桌面壳另行决策。** 视觉验收后比较本地浏览器、QWebEngineView、Tauri/Electron 的文件对话框、快捷键、媒体播放、打包及进程生命周期；本阶段未引入任何一项。

## 已知限制

示例图片来自参考图的画面区域，清晰度受原图限制；视频是静帧模拟，不包含动作和音频。不能拿模拟播放效果评价实际视频解码性能。

项目只存在当前浏览器存储中。清除站点数据会清除原型存档，可先导出 JSON；当前没有导入文件能力。侧栏开关/模型/联网等界面状态不承诺刷新后恢复。

120 镜头通过可用性验证，未进行数千镜头虚拟化、拖动剪辑、成片拼接或实际 4K 多路视频测试。缩放测试为浏览器等效条件，不是混合 DPI 物理双屏验证。

最终视觉接受与正式迁移决定由用户完成。
