# 版本记录

## v0.1.2

- 新增分镜直接创建，按列表自动编号，删除后连续重排，原名称留存且引用 ID 不变。
- 角色和场景改为纵向整行布局；图片、视频工作流分开选择，高清放大仅在图片菜单中。
- 隐藏不适用的参数及参考图输入，文生模式不提交隐藏的参考；图片摘要不再显示 H3 时长。
- 参考图片可上下移动，电影 LoRA 关闭时禁用强度；去掉重复历史按钮及卡片右键中的放大入口。
- 内置 Qwen/H3 生产提示词指南与来源哈希，修正 H3 参考模式为六段结构，明确文字助手看不到图片。
- AI 不能向角色/场景生成视频；分镜素材关联只接受已有角色/场景，避免自引用和分镜循环引用。

## v0.1.1

- 视频卡读取实际视频的第一帧，缓存缩略图，旧项目打开时也可显示。
- 角色、场景、分镜卡增加明确的删除按钮；确认后可解除引用，保留已有输出。
- 所有卡片增加生成历史按钮；显示版本缩略图、提示词、参数、失败/取消记录，支持恢复选定版本。
- 增加标明来源的子 agent 建议导入，临时代替未启用的 DeepSeek 进行集成测试。
- 修正 AI 生成建议被取消时的回执，避免把打开窗口误报为已提交。
- 原 v0.1.0 发布目录保留。
