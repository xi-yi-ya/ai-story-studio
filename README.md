# XY Studio — v1.2.0

面向个人短故事创作者的 Windows 桌面工作台。Vue 3 是唯一正式界面，以 QWebEngineView + QWebChannel 连接原有 Python 后端；调用本机 ComfyUI，DeepSeek 用于对话、故事组织和生成建议。

## 启动

1. 启动已安装节点和模型的 ComfyUI，默认 `http://127.0.0.1:8188`。
2. 双击 `releases/v1.2.0/XY-Studio/XY-Studio.exe`。发布包需保留整个 XY-Studio 文件夹，不能只复制 EXE。
3. 新建空项目文件夹，或打开已有 `project.json`。项目可放在任意可写目录。
4. 在设置中填 DeepSeek API Key（可以暂时不填，手工生成正常使用）。密钥存入 Windows 凭据管理器，不写入项目或 Git。

源码运行：Python 3.12，安装 `requirements.txt`，执行 `npm --prefix frontend ci` 和 `npm --prefix frontend run build`，再运行 `python main.py`。本机已创建 `.venv`，可运行 `run.ps1`。构建 Windows 包：`scripts/build.ps1`；不覆盖已有版本目录。开发测试：`python -m pytest tests --basetemp local-data/pytest-local`（仅用此专用临时目录）。

## 使用

v1.2.0 改为先生成、再选用。顶部“生成图片 / 生成视频”与 AI 助手并列；所有新结果先进入图片库或视频库，不自动替换角色、场景或分镜。角色与场景从图片库添加，只显示图片和名称；分镜从库中添加或替换图片、视频。AI 可直接针对引用图片提出图生视频审阅，无需先创建分镜。审阅显示实际参考图，可放大、排序和移除；再次生成恢复原提示词、参数及原输入图片。“基于此图继续编辑”才把当前结果作为新输入。支持内部图片拖入 AI，以及 Windows 图片/视频文件拖入库、AI 或参考区。详见 [本版交付与验收](docs/RELEASE-v1.2.0.md)。本版仅在本机交付，按用户要求暂停上传。

当前操作顺序：

1. 使用顶部生成入口，或将图片拖入 AI 后说明要编辑/生成视频；确认参数后排队。
2. 在图片库/视频库预览结果，不满意时使用“再次生成”。空库可先生成或导入；已生成但未选用的素材仍保留在库与任务历史中。
3. 在角色、场景中“添加角色 / 添加场景”，选择图片并填写可选名称；不填写则沿用图片名称。分镜卡片中“添加图片 / 添加视频”，选择库中素材。
4. 角色、场景和镜头的历史仍可查看与切换。取消选用不改变资产；仅生成不增加资产版本。旧项目的描述、ID、版本和素材关联保留。

- 左侧导航进入角色、场景、分镜工作区。角色/场景从图片库添加，可改名称、替换图片、右击发送给 AI、查看版本或删除；旧描述仍在项目中保留。

v0.1.2：三个页面均纵向排列整行卡片。新增分镜无需预输入，按顺序自动编号，删除后连续重排；旧名称保留在项目 original_name 字段中，关联 ID 不变。图片入口仅提供图片工作流及高清放大，视频入口仅提供 H3；隐藏无关参数，参考图可上下调整顺序。已有图片时默认打开编辑模式。角色和场景保留图片功能，视频仅放在分镜中。

内置 AI 包含本机 Qwen/H3 提示词 skill 的生产指南快照，随应用打包，无需安装 Codex 技能。Qwen 区分文生图与编辑，H3 区分普通三段与参考模式六段；来源哈希见 docs/prompt-skills.json。没有图片识别及严格 PE 快照复现能力，不能声称实际看过素材。提示词时间线仍需与参数窗口中的最终时长核对。

初版测试可用“导入子 agent 建议”加载 GPT-6.1 Sol high 生成的建议文件，使用同一审阅/执行路径，不需要 DeepSeek Key。此入口是离线建议导入，不代表桌面应用已接通 Codex 实时对话服务。2026-10-09 已通过真实 DeepSeek 对话与多轮生成衔接测试，详见验证记录。

## 工作流范围

| 功能 | 工作流与控制 |
|---|---|
| Qwen Image 2.1 文生图 / 编辑 | 文生图默认 BF16/16-bit PNG；编辑默认 INT8/8-bit PNG、沿用主图尺寸；支持自定义 MP、比例及最多 16 张编辑参考 |
| Krea2 文生图 | 9 种风格 LoRA 分别启停，启用时自动附对应触发词 |
| Krea2 角色四视图 | QuadView LoRA 启停，参考图和输出尺寸 |
| H3 图生视频 | 10Eros beta4 INT8，电影 LoRA 启停和强度，比例、MP、秒数 |
| H3 参考生视频 | 同底模，1–9 张有序参考图片，电影 LoRA 启停和强度 |
| RFMSR | 1–8 倍（0.1 步进）、采样步数、预期输出尺寸 |

另提供 H3 文生、首尾帧模式，由同一 H3 节点建立；具体实测范围见 `docs/VALIDATION.md`。

**按用户要求排除独立“电影感10Eros+Beta3”工作流；不接入断开的 Turbo LoRA；忽略之后新增的工作流。** 普通 H3 的电影质感 LoRA 保留。不开启的 LoRA 从 API 图中移除，不依赖编辑器 mode 标记。

## 第一版边界

- DeepSeek 已验证桌面发送/接收，以及真实 API 保存故事、Qwen 改图、下一轮引用新图生成 H3 视频。模型名在设置中可改，实测 deepseek-flash。未实现同一批建议自动等待未来输出并串联所有生成任务。
- H3 使用 24fps，按原表达式向上对齐为 `17k+5` 帧。输入 2 秒得到 56 帧，约 2.33 秒；界面显示实际时长。默认低规格方便首测，高规格没有可运行保证。
- Qwen 编辑参考不做居中裁剪，默认按第一张图尺寸生成；自定义尺寸另选输出画布。文生图保存原始 16-bit PNG，浏览器预览不等同于 16-bit 色彩审片。
- H3 参考模式本版只接图片；视频参考、音频参考、时间线剪辑、成片拼接、自动连续性审片尚未实现。
- 版本记录保存生成意图、参数、引用素材快照；没有完整的素材分支合并或镜头首尾帧自动比较。
- 程序不安装/下载模型，不改写用户 ComfyUI 工作流，不打包模型。需要同样的节点和模型文件名。`docs/workflow-sources.json` 记录六份批准来源的文件哈希。
- 任务提交超时标记未知，不自动重交；有 prompt_id 可以恢复查询。ComfyUI 重启会丢失其内存队列/历史，未知任务需人工核对。任务日志可在项目 `jobs` 文件夹查看。
- 不要同时用两个程序实例编辑同一项目；项目 JSON 是单用户存储。

## 目录与迭代

`studio/` 应用和后端；`tests/` 离线测试；`scripts/` 构建与显式人工启动的本机生成测试；`docs/` 需求、来源及验证。

源码通过 Git 提交和 `v0.1.0` 标签留档。`releases/v0.1.0/` 保存可运行包；后续版本使用新目录，保留旧包。`.venv`、生成素材、日志、项目、发布二进制不提交 Git。项目外部图片在导入时复制，原文件不修改。

## 实现依据

原生独立实现，没有复制 EasyAI 等项目代码。DeepSeek 接口依据官方 [Tool Calls 文档](https://api-docs.deepseek.com/guides/tool_calls/)，发布依据 [PyInstaller 文档](https://pyinstaller.org/en/stable/usage.html)。ComfyUI 适配以本机 `/object_info` 和批准工作流为准。
